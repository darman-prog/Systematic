SCRIPTS EN LINUX

✓  ¿Qué es un Script?

Es  un archivo que  contiene  un conjunto de comandos que  son ejecutados desde  el primero hasta el último de  forma
secuencial.

✓  Como crear un Shell Script

Para crear el script se crea un nuevo archivo con el comando touch o el editor nano y se le agrega la extensión .sh, por
ejemplo:

touch tarea.sh
nano tarea.sh

una vez creado se le indica al sistema que el archivo es un script, para esto se coloca como primera linea:
#! /bin/bash

- Donde #! Corresponde al sha bang, que se usa para indicar al sistema que la secuencia  a continuación corresponde a las
instrucciones de comando, este paso es importante para que las líneas sean procesadas como tal.
- La parte /bin/bash indica el shell que se va a utilizar para ejecutar los comandos.

En un script se pueden utilizar todos los comandos que se han visto dependiendo del proceso que se desee, además se
pueden  utilizar  muchas  otras  herramientas  como  operadores  aritméticos,  comparadores,  estructuras  condicionales,  e
incluso agregar comentarios con el símbolo #

Ejemplo 1:
se  creará  un  script  llamado  prueba.sh  que  creará  una  carpeta  llamada  documentos,  en  el /root  y  dentro  de  ella  otra
carpeta llamada prueba y en ella un texto llamado tareas.txt

#! /bin/bash
# ejemplo de Script
cd /root
# para ir al directorio del root
mkdir documentos
# Crear una carpeta llamada documentos
mkdir documentos/prueba
# Crear una carpeta llamada prueba en documentos/
touch /root/documentos/prueba/tareas.txt
# Crear un txt llamado tareas.txt
echo ‘hola mundo’ > /root/documentos/prueba/tareas.txt
# introducir el texto hola mundo en tareas.txt
cat /root/documentos/prueba/tareas.txt
# desplegar en pantalla el contenido de tareas.txt

Ejecutar el script: Para ejecutar nuestro el script se le dan permisos de ejecución con  el comando chmod.

chmod 775 prueba.sh
ls
./prueba.sh

Ejemplo 2:
Crear un script ejemplo.sh, que ejecute la siguiente tarea: que ingrese al directorio /mycatedraserverfiles y allí cree un
directorio llamado mydirectorio y en el un archivo de texto prueba.txt con su correo, luego lo debe comprimir en zip y
copiarlo en root con el nombre: mycopia.zip y que muestre el contenido de /root

nano ejemplo.sh
#! /bin/bash
cd /mycatedraserverfiles
mkdir mydirectorio
echo ‘correo@uts.com’ > prueba.txt
zip –r mydirectorio.zip mydirectorio
cp mydirectorio.zip /root/mycopia.zip
unzip –v /root/mycopia.zip

se guarda y se dan permisos y se ejecuta

chmod 755 ejemplo.sh
./ ejemplo.sh
