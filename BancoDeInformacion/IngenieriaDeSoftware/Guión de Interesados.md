# Descripción General del Proyecto

La compañía multinacional Naibe Incorporated, ha decidido remplazar el sistema de planeación estratégica ERP que lleva utilizando durante 18 años en Colombia. La compañía Naibe Colombia, subsidiaria de Naibe Incorporated ha elegido un software de clase mundial para tal fin (JDE).

Las razones para remplazar el Software anterior son varias, en particular contar con una sola plataforma a nivel mundial (reportes corporativos interfaces corporativas, consolidar aplicaciones: mantenimiento, licenciamiento), tener un software que permita manejar información estructurada (actualmente no lo hace), mejorar la mantenibilidad del sistema (corporativa versus local y evitar el uso de emuladores).

Para tal fin Colombia sería la 3ª implementación del contratista Pepesoft para Naibe Incorporated. La contratación de este tema se hizo internacionalmente por un valor sin licencias cercano a los 600 USD. Las compañías firmaron un contrato a nivel internacional que cubre a Colombia.

Las responsabilidades del proveedor son las de:

* Levantar la información de procesos y documentarla (Blueprinting)
* Adaptar el SW a las necesidades del negocio (parametrización, necesidades, reportes, documentación, etc)
* Instalar el software en la plataforma provista por Naibe Incorporated, hosting mundial en Kangaroo (Australia)
* Realizar el entrenamiento a los usuarios principales (KUs)
* Ajustar el software según lo identificado en las pruebas de acuerdo al documento de alcance (Blueprinting)
* Asistir en el cargue de datos (cargar en la base de datos del SW y proveer las plantillas para el cargue de datos)
* Guiar en el proceso de transición entre sistemas (Cutover)
* Acompañar y soportar la operación durante el primer mes de operación
* Proveer el soporte de 3er nivel de lo instalado para el Software

La plataforma integrada provista (JDE) incluye un software de manufactura (Add-in), para la manufactura de la industria de Naibe Incorporated. Este software que debe ser integrado se llama Peas (Peras).

Dado que el proyecto en las instalaciones previas no ha sido exitoso (tiempo, calidad y/o costos), se ha decidido contratar a un gerente de proyecto local que garantice que la ejecución de este proyecto sea exitosa. El proyecto tiene un presupuesto aprobado, y la mejor fecha para salir en producción sería al final del año fiscal e inicio del nuevo (primeros días de Enero), pero es evidente que esta fecha no es factible y se empezará a operar en el mes de Febrero.

La compañía Pepesoft provee consultores nacionales y extranjeros que no residen necesariamente en Colombia como el Gerente de Proyecto de Pepesoft cuya base es Mombay. Algunos de estos consultores no hablan español. Al igual que el software que se encuentra en otro idioma (noruego) y su correspondiente documentación que debe ser ajustada por los usuarios claves una vez sea traducida al español.
